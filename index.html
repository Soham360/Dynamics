QUICK START

Your own physics workbench.

  1. Select a model from the topic tabs. Scroll the tabs to see all eight topics.
  2. Drag elements onto the canvas, or click their cards. Click any element to edit its properties. Use arrow keys to move a selected element.
  3. Select the quantity to solve for. Results and worked LaTeX equations update instantly.
  4. Run or scrub the timeline. Answers, equations, and the graph follow the current simulation time. Simulation duration sets the end of the timeline. Positions are schematic.
  5. Switch units, export graph data as CSV, or save an experiment as JSON. Undo/redo restores experiment edits; Ctrl/⌘ Z and Ctrl/⌘ Shift Z work outside text fields.

Each tab is a specific supported system, not a general multibody solver. Placement changes the drawing; properties and model constraints define the physics. Masses use slugs in US units; forces use lbf.
